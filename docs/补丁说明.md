## 1. `engine/review.py` — F1 否定辖域

### 问题

`prohibited_hits()` 回看窗口固定 4 字符：

```python
prefix = answer[max(0, idx - 4):idx]
if not any(hint in prefix for hint in NEGATION_HINTS):
    hits.append(pattern)
```

对 `请先不要自行给药、催吐或强行灌食灌水`：
- 「自行给药」前 4 字 =「请先不要」→ 含「不要」→ 正确遮蔽
- 「强行灌食」前 4 字 =「、催吐或」→ **无否定词 → 误报**

结果：兜底文案自身被判违规 → 审核永远不通过 → 9 例降级兜底。

### 变更

新增 `_CLAUSE_BREAK` / `_CLAUSE_MAX_BACK` / `_clause_prefix()`，
`prohibited_hits()` 改用 `_clause_prefix()` 取代固定 4 字符窗口。

```python
_CLAUSE_BREAK = ("。", "；", "！", "？", "\n", "，", ",", "：", ":", ";")
_CLAUSE_MAX_BACK = 40
```

### 为什么顿号「、」不作为边界

`不要自行给药、催吐或强行灌食灌水` 是否定辖域内的**并列宾语**，顿号切开会再次制造同类误报。
逗号作为边界则保证 `不要自行给药，建议催吐` 中逗号后的「催吐」仍被判为真违规。

### 行为变化

| 输入 | 改前 | 改后 |
|---|---|---|
| 请先不要自行给药、催吐或强行灌食灌水； | `['强行灌食']` ❌ | `[]` ✅ |
| 不要自行给药，但可以自行催吐 | `['自行催吐']` | `['自行催吐']` ✅ 不变 |
| 建议自行催吐 | `['自行催吐']` | `['自行催吐']` ✅ 不变 |

**未放宽任何真阳性判定**——只消除跨顿号的误报。

## 2. `engine/rules.py` — F2 红旗词表缺口

### 问题

`detect_e0()` 对以下输入全部返回 `[]`：百合花、老鼠药、布洛芬、抽搐五分钟。

对照 SKILL.md 原则 1，「误食百合」「疑似中毒」均为红旗 → **实现与规格不一致**。

### 变更

**(a) `RED_FLAGS` 新增「百合」**——对猫必毒，出现即红旗，不依赖「误食/吃了」的前缀搭配。

**(b) `FLAG_NORM` 新增两组映射**

| 类别 | 词条 | 归一为 |
|---|---|---|
| 毒物 | 老鼠药 / 鼠药 / 毒鼠 / 蟑螂药 / 杀虫剂 / 农药 / 除草剂 / 防冻液 | 中毒 |
| 人类药物 | 人用药 / 布洛芬 / 对乙酰氨基酚 / 扑热息痛 / 阿司匹林 / 感冒药 / 安眠药 | 中毒 |

**(c) 新增时长正则层**——「动作 + 数值 + 单位」纯词表表达不了：

```python

_RE_SEIZURE_ONGOING = re.compile(r"抽搐[^，。；！？\n]{0,8}?(?:还没停|没停|不停|不止|持续|连续|反复)")
```

`detect_e0()` 在词表扫描后追加正则层判定，并复用既有 `_is_negated()` 做否定防御。

## 3. `engine/rules.py` — F3 昵称误抽取

### 问题

```python
_RE_NAMED = re.compile(
    r"(?:我的|我家|家里的|家中)?(?:猫咪|猫猫|猫|它)?\s*(?:叫|名字是|名叫)\s*([一-龥A-Za-z0-9]{2,8})"
)
```

前缀**全部可选** → 句中任意位置的「叫」都触发命名结构。

`它一直往猫砂盆跑，每次只尿出几滴，还叫得很惨` → 匹配「叫」+「得很惨」→ 昵称 = `得很惨`
→ 昵称确认路径**短路正文** → 一条泌尿阻塞急症被回成改昵称的客套话。

### 变更

**(a) 负向前瞻**：`叫` 后紧跟动词补语时不视为命名结构

```python
_RE_NAMED_NEGATIVE_TAIL = r"(?!得|了|着|过|个不停|不停|起来|出声|唤|醒|什么|啥|做|起来)"
```

同步应用于 `_RE_NAMED` 与 `_RE_EXPLICIT_NAME_CLAIM`（后者决定是否直写确认档案）。

**(b) 首字黑名单**：结构性虚词不可能是猫名开头

```python
_NICKNAME_BAD_FIRST_CHARS = frozenset("得了着过个起出醒唤叫的之亦而且但")
```

在 `_is_valid_nickname()` 首部否决。

### 行为变化

| 输入 | 改前 | 改后 |
|---|---|---|
| 它一直往猫砂盆跑…还叫得很惨 | `'得很惨'` ❌ | `None` ✅ |
| 我家小白今天吐了 | `'小白'` | `'小白'` ✅ |
| 我家的猫咪叫小咪，是只英短 | `'小咪'` | `'小咪'` ✅ |
| 我家的猫叫大橘 | `'大橘'` | `'大橘'` ✅ |
| 咪咪今天吐了 | `'咪咪'` | `'咪咪'` ✅ |
